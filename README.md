# ST 558 Project 2
## Banking Dataset Explorer
### Ryan Clark

This project builds a Shiny app for exploring data from a Portuguese bank's phone marketing campaigns, and whether clients subscribed to a term deposit. 
Users can subset the data, view and download it, and create contingency tables, numeric summaries, and plots.

- **App:** [Link](https://rclark00.shinyapps.io/project2/)
- **Data:** [Banking Dataset on Kaggle](https://www.kaggle.com/datasets/prakharrathi25/banking-dataset-marketing-targets)
